# clearxコマンド
![test](https://github.com/rito2004/robosys2026_assignment1/actions/workflows/test.yml/badge.svg)

clearxは、コマンドの履歴を自動で記録し画面を消去した後に直近５件の正常終了したコマンドを再表示します。

## 使用方法
- リポジトリをダウンロード後、実行権限を付与します。

  次に以下のコマンドを実行し、自動記録機能をインストールしてください。

  $ ./clearx --install

  インストール後はBashの設定を反映するために以下のコマンドを実行してください。

  $ source ~/.bashrc

  以降は通常通りターミナルでコマンドを実行することで作動します。

- アンインストールしたい場合は以下を実行し、ターミナルを再起動することで自動記録機能が解除されます。
  $ ./clearx --uninstall


## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10~3.14

## テスト環境
- Ubuntu 24.04 LTS
